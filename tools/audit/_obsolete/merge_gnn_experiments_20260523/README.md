# Obsolete Merge / GNN Audit Scripts

This folder keeps the merge/GNN influence audit scripts from the earlier
GNN-centered phase. They are archived for traceability but are no longer part of
the default layout-aware reconstruction path.

Current main direction:

- default reconstruction is layout-aware and no-GNN;
- v8 reconstruction starts from MinerU `middle.json` and rebuilds reading order
  before paragraph continuation;
- old MERGE/GNN experiments are preserved here instead of being deleted.

Do not import these scripts from production code. If one of them becomes useful
again, copy it back deliberately and update this README with the reason.
